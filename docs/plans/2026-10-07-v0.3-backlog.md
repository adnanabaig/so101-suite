# v0.3 backlog

Work found during v0.2 that did not ship in it, grouped by area. Each item
names where it lives. First, run the v0.2 handoff on the G15 and fix what
`so101 doctor --json` and the HIL report turn up; that outranks everything
below.

## Verify on the G15 first

- The Ubuntu install path: apt prerequisites (including the `libusb-1.0-0`
  package name on 24.04), dialout, the udev rules (whether `99-` is early
  enough for ModemManager to honour `ID_MM_DEVICE_IGNORE`), the NVIDIA driver
  and CUDA build choice, `~/.local/bin`, the desktop entry.
- The three stops on the real arm (the HIL checklist), with Collapse speed
  measured on the servos, not just commanded.
- How long one servo health read takes on the real bus, and its effect on a
  30 Hz loop (`scripts/measure_health_latency.py` models 15 ms).
- RealSense color and depth on stock Ubuntu 24.04 (kernel 6.8, V4L2 backend,
  no patched modules), and depth through real LeRobot recording and training.
- MuJoCo rendering through EGL on the NVIDIA driver (`so101 doctor` probes it).
- Training through `python -m lerobot.scripts.lerobot_train` with lerobot 0.6.1
  and accelerate installed.

## Control plane

- Smoother Collapse: set the STS3215 velocity and acceleration registers during
  the descent, so the per-step speed stays near the 15 °/s cap instead of
  peaking near 3× within each 1/30 s step.
- Done in the RC hardening: standalone and RobotManager real-arm paths write
  identity-scoped local state plus a host-global physical-device `energized`
  marker before torque-enable. It survives a crash or normal Halt/port close,
  including across data directories, until aggregate confirmed torque-off or
  an acknowledged physical power cut.
- Done after v0.2.0 and strengthened in RC3: the server and `so101 calibrate`,
  `teleop`, `record`, `replay`, `run` and `eval` take canonical device-global
  locks, independent of data folder and checkout, and those commands refuse
  while a persisted latch is set. The `so101 calibrate` CLI still opens its
  own bus (under the lock).
- A stable machine-readable code on the fault-reset 409 for "cut power first";
  the UI matches the detail text today.
- Command freshness compares the client's wall clock with the server's; use a
  per-lease offset so clock skew between machines cannot shift the window.
- A `so101 reset` CLI command for the E-stop and fault reset bodies.
- Decide whether invalid servo health thresholds should refuse arming instead
  of switching monitoring off with a visible reason.
- Synthesize servo health values in the simulator, so monitoring runs under
  `SO101_BACKEND=sim`.

## Data, training and evaluation

- Done after v0.2.1: the eval router now preflights only registered models,
  resolves checkpoint task and fps defaults, loads one policy for every trial,
  and builds its durable report through `EvalReport.from_trials` with Wilson
  intervals and the actual backend. The Evaluation page can send a task
  override.
- Done after v0.2.1: under `SO101_BACKEND=sim`, policy preflight checks a
  privileged checkpoint's `env_state_names` against the active task before a
  rollout (the follower reports the state since v0.2.1).
- UI for the data-learn fields: preset `trainer` and `requires_torch`, training
  job `progress`, model kind, label and dataset; leave out steps and batch size
  for `bc_baseline`.
- Action chunking and image inputs for the numpy baseline.

## Operator UI

- Exposing camera specs (name, entry) in status, so tiles stop parsing keys.
- Hand tracking loads MediaPipe from a CDN; bundle it for offline use.
- Preflight run from the UI, a servo health panel and a HIL runner page.

  `asyncio.sleep`.
- Explicit `encoding="utf-8"` on every text read and write, with CI running
  `-X warn_default_encoding`.
- A Windows branch for the trainer's process-group stop, an `os.replace` retry
  helper for sharing violations, and a Windows lock for the recorder.
- Run and fix `install/install.ps1` and the macOS path of `install/install.sh`.
- A CI matrix: Ubuntu 24.04, Windows and macOS on Python 3.13, plus Ubuntu on
  3.12, with `MUJOCO_GL=egl` on Ubuntu.
